# public/fonts

The four Brand V2 typefaces, served first party.

Generated by `scripts/build-fonts.py` (`npm run fonts`). Do not add or
edit a file here by hand; the stylesheet next to them is generated from
the same list.

Subset to Latin-1, Latin Extended-A and the punctuation the brand sets.
Nine faces, about 181 kB on disk. A Czech page loads roughly 138 kB of
it, an English page slightly less.

All four families are SIL Open Font License 1.1, which permits hosting
and subsetting. `OFL.txt` carries the licence text.

`postbuild.mjs` inlines `tanmay-fonts.css` into every built page, so
there is no extra request in production. The `<link>` in `index.html` is
what `vite dev` uses.
